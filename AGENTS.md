# Agent rules
- Keep the application local-first and privacy-preserving.
- Never label this product a lie detector or claim that behavioral cues prove deception.
- Do not add deception classification without validated, consented, licensed data and participant-independent evaluation.
- Never claim a Windows build passed unless CI artifacts and smoke tests are verified.
- Avoid placeholder features presented as complete functionality.
- Do not add telemetry or upload participant media by default.
