# Security and participant privacy
- Obtain informed consent before camera, audio, or video collection.
- Camera preview is opt-in and is not recorded by this scaffold.
- Store research records locally and restrict access to participant media.
- Use pseudonymous identifiers; avoid unnecessary personal information.
- Define retention and deletion policies before real-world studies.
- Do not infer deception from gaze, gestures, facial expressions, nervousness, or vocal features.
- Report security issues privately to the repository owner.
